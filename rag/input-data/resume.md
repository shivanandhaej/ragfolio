**Problem the system solves:** Standard operating systems are often too resource-heavy and unpredictable for time-critical embedded applications. This project addresses the need for a lightweight, deterministic operating system capable of handling strict timing constraints in embedded hardware environments.
**System architecture:** The architecture involves a custom-built basic RTOS that interfaces directly with microcontroller hardware. It includes a scheduler to manage multiple tasks, context switching mechanisms, and resource allocation modules to prevent deadlocks and ensure system stability.
**Technologies used:** C/C++ for low-level systems programming, embedded microcontroller architecture, debugging tools.
**Responsibilities:** Shiva was responsible for the end-to-end design and development of the RTOS core. They independently implemented the task scheduling algorithms and established resource management protocols to ensure efficient execution of concurrent operations.
**Interesting engineering decisions:** A major focus was placed on optimizing the scheduling algorithm to improve overall system efficiency during real-time operations, ensuring that high-priority tasks were executed without delay while managing memory constraints typical of embedded devices.
**Impact:** The project successfully demonstrated improved system efficiency for time-critical operations and provided Shiva with profound, hands-on experience in the intricacies of embedded system architecture, kernel development, and hardware-software interfacing.
